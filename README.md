# AWS CloudWatch – EC2 CPU Monitoring & Email Alert

This project demonstrates how to monitor the CPU utilization of an Amazon EC2 instance using AWS CloudWatch and configure an automated email notification when CPU utilization exceeds a defined threshold.

The project helps understand how AWS monitoring and alerting can be implemented to detect high resource utilization and notify administrators for further action.


# Project Objective

-The main objectives of this project are:

-Monitor EC2 instance CPU utilization.

-Create a CloudWatch alarm based on CPU usage.

-Define a CPU utilization threshold.

-Configure an Amazon SNS notification.

-Receive an email when the CloudWatch alarm enters the alarm state.

-Understand AWS monitoring and alerting mechanisms.
